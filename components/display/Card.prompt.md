Default container for panels; flat colour blocks for one featured message.

```jsx
<Card eyebrow="Visão geral" title="Vendas por canal">…</Card>
<Card variant="block" title="Destaque do mês" accent="var(--accent-square)">…</Card>
```

- surface (white) and sunken (#FAF6EB) for everyday panels.
- block #545933 / block-alt #415062 with white text — max one per view, like the institutional template.
- inverse #381416 only for header/footer bands.
- `accent` = the small corner square from the template (#D7B761 on blocks).
