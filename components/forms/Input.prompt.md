Single-line text field with optional label, hint, error and leading icon.

```jsx
<Input label="E-mail" placeholder="nome@nannai.com.br" />
<Input icon="search" placeholder="Buscar cliente" size="sm" />
<Input label="Telefone" error="Informe um número válido" />
```

- Focus: burgundy border + soft pink halo. Error: rose border, burgundy message.
